# Seguridad

## Usa solo la versión oficial

Ejecuta RigWarden únicamente con el comando que aparece en el README de este repositorio o descargando `RigWarden.ps1` desde aquí. No uses copias publicadas en otras webs, vídeos o servidores de Discord: podrían estar modificadas.

## Informar de un problema de seguridad

Si encuentras un fallo de seguridad, **no abras una incidencia pública**. Usa la opción **Security → Report a vulnerability** de este repositorio para avisar de forma privada.
